# mos-cia-8520

The MOS 8520 complex interface adapter, the Amiga's 6526.

| Crate | Registry |
|---|---|
| [`emu198x-mos-cia-8520`](crates/emu198x-mos-cia-8520) | [crates.io](https://crates.io/crates/emu198x-mos-cia-8520) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Amiga machines.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
